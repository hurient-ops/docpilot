# [UI/UX 설계서 v3] 로컬-클라우드 하이브리드 AI 기반 통합 문서·미디어 자동화 플랫폼 (DocPilot)

---

## 1. UI/UX 디자인 개요 및 화면 구조 (Architecture Overview)

### 1.1 시스템 구조 및 디자인 철학
본 시스템은 사용자가 로컬 컴퓨터 및 사내 공유 폴더의 문서를 손쉽게 탐색, 위치 추적 검색, 오피스 바이너리 재조합, PDF 변환, 다중 문서 비교, 멀티모달 미디어 검색, AI DLP 마스킹 관리를 단일 공간에서 수행할 수 있도록 **Tauri v2 기반 데스크톱 앱 뷰어 / Responsive Web SPA / MS Office & 한글 In-App Add-In**으로 구축됩니다.

* **High-Density Information Architecture**: 실무자가 대량의 문서 메타데이터, 파일 트리, 검색 결과, 라인 Diff, PII 마스킹 상태를 한눈에 파악할 수 있는 고밀도 레이아웃.
* **Format-Centric Visual Cues**: 5대 포맷(PPTX, XLSX, DOCX, HWP/HWPX, PDF)에 정교하게 매핑된 브랜드 컬러 배지를 부여하여 시각적 인지 속도 극대화.
* **Seamless AI Engine Switcher & Hardware Auto-Diagnostic**: 상단 네비게이션 바에서 🟢 **로컬 AI 모드** (하드웨어 추천 등급 배지 표기)와 ☁️ **클라우드 AI 모드**를 즉시 토글할 수 있는 인터랙션 제공.
* **Split-Pane Interactive Preview & Dockable Add-In Panel**: 검색 결과 우측 분할 실시간 미리보기 및 MS Word, PowerPoint, 아래한글 내부에 직접 도킹되는 플러그인 레이아웃 제공.

## 2. 화면별 상세 레이아웃 & 스펙 (Screen Layout Specifications)

### 2.1 화면 1: 디렉토리 대시보드 & 폴더/포맷 선택기 (Directory Analytics & Folder Selector)
* **목적**: 지정된 로컬 폴더(하위 폴더 포함) 내 포맷별 문서 수량, 용량, 슬라이드/페이지 통계, 증분 색인 상태 및 파일 트리를 대시보드로 시각화.
* **상세 구성 요소**:
  1. **폴더 선택기 (Folder Picker)**:
     * 경로 직접 입력 필드 (`D:\업무자료`)
     * `[폴더 선택]` 탐색기 열기 버튼 + 최근 사용 폴더 드롭다운
     * `[하위 폴더 포함]` 토글 스위치 (기본값: ON)
     * `[폴더 보안 정책]` 라디오: `(●) 로컬 전용 (local_only)` / `( ) 클라우드 허용 (cloud_allowed)`
  2. **포맷 필터 칩 (Format Selector)**:
     * `[전체]` `[PPTX]` `[XLSX]` `[DOCX]` `[HWP/HWPX]` `[PDF]` 동적 체크박스 칩 (문서 개수 배지 표기)
  3. **통계 카드 요약 (Summary Cards Grid)**:
     * 총 문서 수, 총 용량, 평균 페이지/슬라이드 수, 색인 완료율(%), PII 개인정보 감지 건수, 암호/손상 오류 건수
  4. **포맷별 용량/수량 시각화 차트**:
     * 도넛 차트 (포맷별 문서 비율), 바 차트 (폴더 계층별 용량 분포)
  5. **디렉토리 파일 트리 & 접이식 에러 패널**:
     * 좌측 사이드바 계층 트리 뷰. 클릭 시 메타데이터 Modal 팝업.
     * 하단 **[손상/암호 걸린 파일 오류 목록 패널]** (접이식): 클릭 시 암호 입력 모달 또는 건너뛰기 설정.

### 2.2 화면 2: 위치 추적형 하이브리드 검색 & 분할 미리보기 (Location-Aware Search Workspace)
* **목적**: 키워드, 제목, 문맥 묘사를 기반으로 원본 문서의 정확한 파일 경로와 물리적 위치(페이지/슬라이드/시트)를 정밀 매핑하고, 우측 분할 패널에서 원본 렌더링 이미지를 미리보기.
* **상세 구성 요소**:
  1. **검색 컨트롤 바 (Search Bar & Options)**:
     * 통합 검색어 입력창 + `[검색]` 버튼
     * Hybrid Ratio 슬라이더: Dense Vector(의미 검색) ↔ Sparse BM25(정확 키워드) 비중 조절
     * `[GraphRAG 관계망 보기]` 토글 스위치
  2. **결과 테이블 & 우측 분할 미리보기 (Split-Pane Layout)**:
     * **좌측 결과 리스트**:
       * 포맷 배지, 파일명, **[물리적 위치: X페이지 / Y번째 슬라이드 / Z시트]** 배지
       * 문맥 스니펫 (검색어 형광펜 하이라이팅)
       * 행 클릭 시 우측 미리보기 패널 즉시 연동
       * 액션 버튼: `[원본 위치 열기]`, `[병합 목록에 추가]`, `[비교에 추가]`
     * **우측 분할 미리보기 패널 (Interactive Page Preview)**:
       * 선택한 위치의 고화질 페이지 렌더링 이미지
       * 상단 페이지 이동 컨트롤 (`[◀ 이전 p.3]`, `[다음 p.5 ▶]`, `[100%]`)
       * `[현재 페이지 원본 오피스로 열기]` 버튼

### 2.3 화면 3: 목차 기반 추출, 바이너리 재조합, 템플릿 매핑 & PDF 워크스페이스 (Document Merger)
* **목적**: 목차 및 추출 페이지 명세를 수신하여 원본 서식이 유지된 신규 오피스 파일을 합성하거나, 기업 표준 템플릿 매핑 및 PDF ⇄ 5대 포맷 양방향 변환 실행.
* **상세 구성 요소**:
  1. **좌측 목차 빌더 Panel (Outline Builder)**:
     * **목차 항목 편집기**:
       * 목차 노드 추가/삭제 및 드래그 앤 드롭 순서 변경 인터페이스
       * 항목별 AI 추천 후보 페이지 클릭 및 직접 범위 지정 (예: `2026_사업계획서.docx` ➔ `3p~7p`)
     * **기업 표준 템플릿 매핑 드롭다운**:
       * `[기본 원본 서식 유지]` / `[기업 표준 PPTX 템플릿 A]` / `[기업 표준 Word/HWP 양식]`
     * **PDF ⇄ 오피스 포맷 양방향 변환 파이프라인**:
       * 변환 모드: `[PDF → 오피스 (DOCX/PPTX/HWPX)]` / `[오피스 → PDF]`
       * **호환성 사전 점검 배너 (Pre-flight Banner)**: 스캔본 이미지 감지 시 `[Local OCR 적용]` 자동 체크 안내
  2. **우측 미리보기 캔버스 (Live Preview Grid)**:
     * 추출/변환 결정된 페이지/슬라이드의 섬네일 그리드 타일
     * 섬네일 각 모퉁이에 **Document Lineage (원천 출처 메타 배지)** 표기
  3. **하단 결합 실행 바 (Bottom Control Bar)**:
     * Output 포맷 선택 `[(●) PDF  ( ) PPTX  ( ) DOCX  ( ) HWPX]`
     * `[병합 파일 만들기]` 버튼 (로컬 '결과물 저장 폴더'에 비파괴 저장)

---

### 2.4 화면 4: 다중 문서 비교 분석 화면 (Multi-Doc 3-Tab Diff & LLM Report)
* **목적**: 2개 이상의 문서를 원자 단위로 라인 비교하고, 수치 변동 전용 탭과 LLM 문맥 요약 리포트 제공.
* **상세 구성 요소**:
  1. **문서 선택 영역**:
     * 기준 문서(A) 드롭다운 vs 비교 대상 문서(B, C...) 다중 선택
  2. **3원화 결과 탭 (3-Tab Result View)**:
     * **탭 1: 📝 AI 문맥 요약 탭**: LLM 기반 조항/수치 변동 종합 분석 요약 리포트
     * **탭 2: 🔍 좌우 상세 Line Diff 탭**: 문단 라인 단위 대조 스크롤 (추가 `#DCFCE7`, 삭제 `#FEE2E2`, 수정 `#FEF9C3`)
     * **탭 3: 📊 표·수치 변동 전용 탭 (Numerical Changes)**: 계약금, 금리, 일자, 수치 변동 셀만 모아서 대조 표 형태로 출력 (예: `계약금 비율: 10% ➔ 20% 인상`)
  3. **내보내기 버튼**: `[비교 리포트 DOCX/PDF 다운로드]`

---

### 2.5 화면 5: 로컬 멀티모달 미디어 특징 검색 화면 (Multimodal Media Search Gallery)
* **목적**: 로컬 폴더 내 이미지 및 동영상 미디어를 자연어 특징 묘사만으로 탐색.
* **상세 구성 요소**:
  1. **자연어 특징 입력바 (Text Query Bar)**:
     * 예) "파란색 셔츠를 입고 회의실에서 발표하는 장면"
     * 대상 선택: `[전체]` `[이미지]` `[동영상]`
     * 유사도 임계값 슬라이더
  2. **미디어 갤러리 Grid (Gallery View)**:
     * 유사도 점수(%), 파일명, EXIF 정보
     * **동영상 매칭 타임스탬프 표기**: 부합하는 시점 (예: `01:23 ~ 01:45`) 및 호버 미리보기
     * 클릭 시 미디어 비디오 플레이어 Modal 팝업 및 해당 시점 즉시 재생

---

### 2.6 화면 6: AI DLP / PII 개인정보 마스킹 관리 센터 (Security & Masking Center)
* **목적**: 문서 내 주민번호, 계좌번호, 대외비 문구 탐지 현황 확인 및 블라인드 마스킹 규칙 설정.
* **상세 구성 요소**:
  1. **개인정보 감지 현황 테이블**:
     * 감지된 파일명, 개인정보 유형(주민번호, 전화번호, 계좌, 대외비 키워드), 위치(페이지/행), 마스킹 처리 상태
  2. **마스킹 규칙 제어 바**:
     * `[주민번호 자동 마스킹 (●●●●●●-●●●●●●●)]` 토글
     * `[대외비 키워드 사용자 정의 필터]` 입력 필드
     * `[선택 마스킹 적용 및 원본 보호 저장]` 버튼

---

### 2.7 화면 7: 작업 내역 로그 & 작업 제어 화면 (Job History & Operations)
* **목적**: 과거 실행된 문서 색인, 바이너리 병합, 포맷 변환, 비교 분석 이력을 한눈에 조회 및 관리.
* **상세 구성 요소**:
  1. **작업 내역 테이블 (Job History Log Table)**:
     * 작업 ID, 작업 유형(색인/병합/변환/비교), 대상 파일 수량, 수행 일시, 소요 시간, 상태(완료/진행 중/오류)
  2. **작업 관리 액션**:
     * `[결과 파일 저장 폴더 열기]`, `[재시도]`, `[로그 다운로드]`

### 2.8 화면 8: MS 오피스 & 한글 내장 In-App 플러그인 (Add-In Dockable Panel)
* **목적**: MS Word, PowerPoint 및 아래한글(HWP) 상단 리본 메뉴에 도킹되어 편집 도중 즉시 파이프라인 호출.
* **상세 구성 요소**:
  1. **리본 메뉴 탭 (Ribbon Menu)**:
     * `[AI 통합 검색]`, `[이전 보고서 단락 불러오기]`, `[표/차트 바이너리 삽입]`, `[라인 Diff 비교]`
  2. **우측 도킹 사이드바 (Dockable Sidebar)**:
     * 자연어 검색창, 연관 원본 슬라이드/단락 섬네일, `[현재 위치에 즉시 인서트]` 버튼

## 3. UI 디자인 시스템 & 컴포넌트 명세 (Design System & Components)

### 3.1 Color Palette
* **Primary / Neutral**: Dark Navy (`#0F2A4A`), Slate (`#1E293B`), Light Gray (`#F8FAFC`)
* **Accent / Active**: Indigo Blue (`#2563EB`), Teal / Local AI (`#0D9488`), Amber / Cloud Warning (`#D97706`), Red / Error (`#DC2626`)
* **Format Badge Theme**:
  * **PPTX**: Orange (`#EA580C`, Background: `#FFEDD5`)
  * **XLSX**: Green (`#16A34A`, Background: `#DCFCE7`)
  * **DOCX**: Blue (`#2563EB`, Background: `#DBEAFE`)
  * **HWP/HWPX**: Cyan (`#0284C7`, Background: `#E0F2FE`)
  * **PDF**: Red (`#DC2626`, Background: `#FEE2E2`)
  * **Security / DLP**: Emerald Green (`#059669`) / Rose Red (`#E11D48`)

### 3.2 Typography & Iconography
* **Font Family**: Pretendard, Noto Sans KR, Inter (가독성 중심 Sans-serif)
* **Icon System**: Lucide Icons (`Folder`, `FileText`, `Search`, `Scissors`, `GitCompare`, `Image`, `ShieldCheck`, `Lock`, `Settings`, `History`, `Cpu`, `Cloud`)

### 3.3 Target Resolution & Responsiveness
* **Target Environment**: Tauri v2 Desktop App (Window / macOS), Responsive Web SPA, MS Office / Hancom VSTO Add-In
* **Screen Resolution**: 1920x1080 (FHD) 최적화, 최소 1280px 데스크톱 대응 반응형 레이아웃
